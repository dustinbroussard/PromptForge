# PromptForge

PromptForge is a prompt management PWA for creating, organizing, and enhancing prompts.

## Features

- Create, edit, delete, and organize prompts with tags
- Search, filter by tag, and sort prompts
- Prompt detail modal with quick copy to clipboard
- Import/export prompts as JSON (with optional settings)
- AI enhancement via OpenRouter (optional)
- Theme toggle with system preference fallback
- PWA offline support and install prompt

## Security

- OpenRouter API keys are stored in localStorage; use a low-privilege key and rotate it regularly.
